Amity University Clone

A modern educational portal showcasing academic programs, campus life, admissions, placements, and student resources.

HTML5 Bootstrap 5 JavaScript

README.md

This project is a front-end clone of the Amity University website developed using HTML, CSS, Bootstrap 5, and JavaScript.The website provides information about admissions, courses, campus facilities, placements, and student activities.

Core Features

  • Responsive Bootstrap 5 Design
  • Interactive Navigation Menu
  • Admission Information Section
  • Courses & Programs Showcase
  • Placement Statistics Section
  • Campus Life Gallery
  • Contact & Inquiry Form
